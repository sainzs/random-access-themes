# Source of Truth Manifest

This repo is palette-first.

- Edit the canonical palette YAML files in `palette/`.
- Regenerate the terminal exports and README visuals from those palettes.
- Treat the remaining editor ports, integrations, docs, and scripts as curated repo files unless a generator explicitly owns them.

## Canonical palette files

These are the only hand-edited palette inputs that define the four flavors:

- `palette/random-access-theme.yaml`
- `palette/veridis-theme.yaml`
- `palette/voyager-theme.yaml`
- `palette/amnesiac-theme.yaml`

## Generated outputs

These files are generated from the palettes and should not be edited by hand:

- Terminal exports in `themes/alacritty/`, `themes/ghostty/`, `themes/iterm2/`, `themes/kitty/`, `themes/pi/`, `themes/wezterm/`, and `themes/windows-terminal/`
- Repo visuals in `assets/flavors.svg`, `assets/palette-strips.svg`, and `assets/preview.svg`
- Portable preview export in `assets/preview.png`, derived from `assets/preview.svg`
- Design tokens in `tokens/` (`design-tokens.json`, per-flavor `.json`, `random-access-theme.css`, `tailwind.js`)
- Freshness metadata in `themes/.checksum` and `assets/.preview-checksum`
- Release bundle contents in `dist/` when `scripts/build_release.sh` runs

## Curated repo files

These files are authored directly and are not generated by the palette pipeline:

- `README.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, and the docs in `docs/`
- Generator and validation scripts in `scripts/`
- Integration configs in `integrations/`
- Editor theme ports in `themes/vscode/`, `themes/sublime/`, `themes/zed/`, and `themes/neovim/`
- The six phosphor pi themes, `themes/pi/reckoner-*.json`. Hand-authored, one
  tube each, and deliberately outside the palette pipeline: they are monochrome
  by design and the generator exists to spread a cool-spectrum accent family
  across four flavors. Promoting them to palettes — and so to all thirteen
  platform exports — is the open question in `PLAN.md`.
- `docs/phosphor-themes.md` and the screenshots in `assets/phosphor/`
- CI and packaging glue such as `.github/workflows/validate.yml` and `scripts/build_release.sh`

## Archived / non-canonical themes

Older experimental themes (e.g., `bioluminescence`, `terminal-chic`) are kept in
`archive/` for reference but are not part of the four-flavor public contract.

`reckoner-dusk` used to be listed here. It has been promoted to `themes/pi/`
rather than archived, because the refined version of it — identical in all
seventeen vars, differing only in a thinking ramp that no longer climbs to 80%
lightness through 110° of hue — came back from the reckoner project. The
defective copy is gone; git has it.

## Operating rule

If a change affects the palette story, prefer updating the canonical YAML first, then refresh the generated outputs with:

```bash
make check
# or individually:
python3 scripts/generate.py
python3 scripts/render_repo_visuals.py
python3 scripts/export_tokens.py
python3 scripts/validate_theme.py
```
